\# INC-001 - Computer Performance Troubleshooting Scenario



\## 1. Incident Overview



\*\*Incident ID:\*\* INC-001

\*\*Category:\*\* Windows Performance

\*\*Priority:\*\* Medium (provisional)

\*\*Environment:\*\* Simulated Windows 11 end-user workstation

\*\*Affected Users:\*\* 1

\*\*Incident Type:\*\* Simulated Help Desk L1 scenario

\*\*Status:\*\* In Progress



\## 2. User Complaint



The user reports that their computer has become noticeably slower since the morning.



Applications take longer than usual to open, and the system occasionally freezes for several seconds before becoming responsive again.



The issue appears to affect multiple applications rather than a single program.



\## 3. Initial Information Gathering



The following information was collected during the simulated initial assessment:



\- The issue started this morning.

\- Performance degradation has continued throughout the morning.

\- Multiple applications are affected, including Microsoft Edge and Microsoft Teams.

\- Only one employee has reported the issue.

\- Windows updates were installed the previous day.

\- The system occasionally freezes for several seconds and then recovers.



\## 4. Initial Scope and Impact



\- \*\*Affected user:\*\* One employee.

\- \*\*Affected device:\*\* One Windows 11 workstation.

\- \*\*Business impact:\*\* Reduced user productivity due to slow application launches and intermittent system freezes.

\- \*\*Service availability:\*\* The workstation remains operational, but performance is degraded.



\## 5. Initial Assessment



The symptoms suggest a possible system resource or background-process issue.



Further investigation is required before identifying a root cause or recommending remediation.



No specific hardware failure, software fault, or Windows service issue has been confirmed.



\## 6. Scenario Scope



This is a simulated troubleshooting exercise designed to demonstrate a structured Help Desk L1 investigation.



All diagnostic values and incident-specific findings documented in this scenario are simulated unless explicitly identified as observations from a separate real-device diagnostic exercise.
